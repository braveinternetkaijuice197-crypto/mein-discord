# Nachtwache – Landingpage für Bot- und Website-Hosting

Statische Startseite für einen Hosting-Dienst (Discord-Bots und Websites). Reines HTML und CSS, ohne Build-Schritt.

## Lokal ansehen
`index.html` im Browser öffnen.

## Auf GitHub veröffentlichen
1. Neues Repository erstellen und diese Dateien hochladen.
2. Unter **Settings → Pages** den Branch `main` und den Ordner `/ (root)` wählen.
3. Die Seite ist danach unter `https://<name>.github.io/<repo>/` erreichbar.

## Anpassen
- Name, Texte und Preise in `index.html` ersetzen (alles Platzhalter).
- Kontaktadresse bei `mailto:` eintragen, Impressum und Datenschutz ergänzen.

## Hinweis
Das ist nur die Website. Das eigentliche Hosting (Server, Container, Bot-Verwaltung, Zahlung) ist ein eigenes Backend-Projekt.
