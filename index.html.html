Häufige Fragen

Kann ich meinen Bot von GitHub deployen?

Ja. Verbinde dein Repository, wähle einen Branch, und jeder Push startet ein neues Deployment.

Welche Sprachen werden unterstützt?

Node.js und Python für Bots, HTML, CSS und JavaScript für Websites.

Was passiert, wenn mein Bot abstürzt?

Er wird automatisch neu gestartet, und der Fehler steht in deinen Logs.
